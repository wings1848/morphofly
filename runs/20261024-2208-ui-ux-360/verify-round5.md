## 好消息：本地代派在真机上真的会触发

```
16:43:20.759 WARN 这一轮没有调用任何工具 —— 模型只说了话没干活 reply=好，查着呢
```

**机制成立**：模型只说不动 → 本地拿用户原话代派 → 立刻返回「好，干完说」。

## 坏消息：派到了家目录，DSH 建会话失败

```
16:46:35 🔔 主动汇报 task=task_..._009 report=失败了：出错了：建 DSH 会话失败
```

根因（已修，commit `3b113ad`）：`Dispatcher::new` 会把 context.dir 初始化成
`default_dir`（配置里是 `/home/wings`），所以「上下文非空就返回」永远命中默认目录，
**别名表那段是死代码**。

改成：任务里点名的项目优先 → 会话上下文 → 默认目录 → 内置项目目录；
并且家目录当干活目录等于没指定，专门排除（`is_home_dir`）。+2 测试。

## 打断（barge-in）测试：没测准

或者给 `interruptions` 计数加一条 INFO 日志（下一轮）。
