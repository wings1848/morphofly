# 进展（S4 实现 → 第 2 轮迭代）

**最后更新**：2026-10-24 23:52

## 第 2 轮又修了什么（都在真机上暴露）

| # | 问题 | 真因 |
|---|---|---|
| 1 | 右下角又歪 212px | 启动时前端为显示「推状态 S0」字幕调了 orb_tip，抢在贴边之前 → 归位点拿屏幕正中当基准；随后贴边又按「已撑到 360 宽」算 |
| 2 | 模型只回「好，查着呢」不派活，且没被兜底纠正 | 纠正判据只认云端 `speech_started`，但我们是本地 VAD 提前 commit，云端那条不一定来 → `user_spoke` 恒 false |
| 3 | 项目名被 ASR 听错就直接放弃 | `delegate` 里 dir 不存在只回一句追问，没先查别名表 |

## 修法

1. `ORB_READY` 标志（贴边完成才允许动窗口）+ 贴边前强制回到 148 收起态
   + 尺寸直接按 148 算（不读 `outer_size`，异步读到旧值）+ 位置读回校验
2. 本地 VAD 判定开口时置共享标志，**在事件循环入口**并入 `user_spoke`
   （不能在 `ResponseDone` 里并入 —— 那里会清掉模型文本缓冲区，
   而「是不是在装忙」正是靠那段文本判断的）
3. `delegate` 里先把听错的名字丢进项目别名表；追问措辞不再念绝对路径；
   提示词明确禁止模型「按听来的词自己拼路径」

## 顺带验证掉的

- **拖动逻辑**（A7 的 JS 部分）：浏览器内夹具证明移动 >5px 会调 `startDragging()`、
  松手会调 `snap_orb`，两者各 1 次
- **强制 X11 的副作用**：托盘仍在（StatusNotifier 里有 `main_tray`）；
  内存 PSS **294MB**（V2 记录是 371MB，少 21%）
