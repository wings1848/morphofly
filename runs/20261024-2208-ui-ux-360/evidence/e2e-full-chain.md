## 为什么这一条值得单独记

产品承诺是「喊小蝶 → 说任务 → 它去干 → 干完主动告诉你」。
之前每一环都单点通过过，但**从来没有一次完整走完**：

| 环节 | 以前的状态 |
|---|---|
| 唤醒 | ✅ |
| 说任务 → 派活 | 时好时坏（模型只说不动）→ 现在有本地代派兜底 |
| 派到正确的目录 | 一度派到家目录 → 现在按「任务里点名的项目」解析 |
| DSH 真干活 | ✅（有会话 ID 和 cwd 为证） |
| **干完主动汇报** | ❌ **从来没有兑现过** —— 会话早被超时掐了 |

最后这条是架构问题：DSH 干 1–3 分钟，会话 30 秒空闲回待机、云端 90 秒断开。
修法：会话守卫发现「有结果没念过」就主动开一轮（`Stimulus::ProactiveReport`）。
