## 不做的事（本次范围外）

- 不做第二块窗口（气泡独立窗）—— 会多一个 WebView，内存已经 371MB
- 不换渲染技术（继续 Canvas2D，不引 wgpu/WebGL）
- 不改语音链路、AEC、KWS
- 不做移动端 / Web 端
- 不重做托盘菜单

## 假设（巡检模式默认值，可反悔）

1. **强制 X11 后端（GDK_BACKEND=x11）可接受**。理由：Wayland 下无法定位/置顶，这是硬限制。
   风险：托盘/输入法/缩放有差异，交付时人工核对。
2. **小球窗口 148×148**，球直径约 84px。理由：360 悬浮窗约 60-72px；太小不好点，太大挡桌面。
3. **启动位置：右下角，留 16px 边距**（沿用现有 snap 逻辑）。
4. 配色继续深海青（`#22d3ee`），不引入新色相。
