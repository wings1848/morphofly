# 复盘（S8）

## 一句话

真因是「启动时把状态名当字幕」；第二根因（空窗口黑框）**没被真机复现**，
原本加的全透明过渡被独立 review 否掉后删除——这次最大的收获是「删掉一个看起来有用的 hack」。

## 度量

- 人介入次数：0（巡检模式，H1/H3 自动过；用户只在开始时给了一句话需求）
- 返工轮数：3
  1. 第一版加窗口透明过渡 → 独立 review 指出机制不可靠 + 恢复失败会让球永远不可见
  2. 第一次修后验收 T1/T4 假失败 → 证据里混进了「重启前旧实例」的日志/帧
  3. 最终 main 产物验收再次假失败 → gpd 上有别的 agent 在灌语音（运行期 S2 字幕）
- 闸门一次通过率：7 个闸门中 4 个一次过；G5 返工 2 次后过
- 耗时：约 1.5 小时（其中约 25 分钟在等 GitHub Actions）
- 逃逸缺陷：0（T1–T4 真机 + 独立 subagent 复跑 4/4）

## 做对了什么

1. **先写会变红的验收**（`tools/verify_startup_clean.sh`），再动手改。
2. **真机能出图**：KWin ScreenShot2 8fps 连拍把「4.2 秒气泡」抓下来了；
   换成 spectacle/portal 就什么都看不到（一次 10–15 秒）。
3. **独立 review 拦下一个危险 hack**：GTK widget opacity 对 RGBA 窗口走 Cairo alpha、
   盖不住 WebKit 子窗口，且恢复失败会让球永远不可见。
4. **独立验收拦下两处假证据**：5.95 没归档、旧二进制不打 caption 日志。
   已删掉 5.95、把留存帧 + 复算脚本归档（3.73）。
