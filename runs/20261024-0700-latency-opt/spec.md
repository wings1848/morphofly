# 目标

把 V1 的端到端延迟从 **5082ms** 压到 **800ms 以内**（验收 P1），
并验证真实使用场景「多轮连续对话」可用。

## 为什么单独开一个 run

上一轮（`20261023-2339-v1-dsh-0`）已 done，当时的结论是
「延迟 2–7 秒是 StepFun 平台上限，不可优化」。

**这个结论是错的。** 本轮证明：
1. 换模型能快 2.5 倍（我之前只测了 1 个模型）
2. 关掉服务端 VAD 能再快 2.5 倍

属于「推翻已有结论的重大改动」，值得单独记录。

- 不改 UI
