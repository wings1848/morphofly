## 局限性（诚实标注）

1. **样本只有 23 个音频，不是 100 次循环**。100 次循环测法见验收标准 K1 的复现命令，
   属于阶段 4 正式验收时要补的。
2. **距离容忍（K3）和噪音环境（K4）没测** —— 需要真人拿手机在 2 米外放，或加背景噪声。
3. **Rust 侧还没引入 sherpa-onnx 绑定**。当前是 Python 侧验证，
   正式集成（常驻监听）需要给 core 加 `sherpa-onnx` crate 依赖。
