# 阶段 0 · 接缝 0.1 证据：Tauri 能弹窗

机器：wings-pc（KWin / Wayland + Xwayland）
构建：`tools/pcrun.sh 'cd app/src-tauri && cargo build'` → `Finished dev profile in 9.26s`

## 启动

```bash
tools/pc_app.sh start
```

关键环境变量（KWin/Wayland 下必需，否则窗口创建不了）：

```bash
export XDG_RUNTIME_DIR=/run/user/1000
export XAUTHORITY=/run/user/1000/xauth_bqxIvn
export DISPLAY=:0
export GDK_BACKEND=x11
export WEBKIT_DISABLE_COMPOSITING_MODE=1
export WEBKIT_DISABLE_DMABUF_RENDERER=1
export LIBGL_ALWAYS_SOFTWARE=1
```

## 窗口存在证明

```
$ xdotool search --onlyvisible --name ".*"
18874371 | 蝶梦 | WINDOW=18874371 X=2658 Y=1294 WIDTH=720 HEIGHT=720 SCREEN=0
```

窗口 720×720、无边框、置顶、透明背板。

## 踩坑

| 现象 | 原因 | 解法 |
|---|---|---|
| `Error 71 (Protocol error) dispatching to Wayland display` | WebKitGTK 在 KWin 下走 Wayland 后端失败 | `GDK_BACKEND=x11` |
| `Failed to create GBM buffer of size 720x720` | dmabuf 渲染器在软件栈上不可用 | `WEBKIT_DISABLE_DMABUF_RENDERER=1` |
| `grim` 报 `compositor doesn't support the screen capture protocol` | KWin 没开 screencapture | 用 `spectacle -b -n -f -o`；单窗口用 `import -window` |
