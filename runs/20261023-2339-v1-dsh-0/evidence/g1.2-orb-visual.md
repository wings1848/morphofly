## 踩坑（这条很关键，几乎浪费了 1 小时）

**Tauri 2 必须有 `capabilities/default.json`，否则 IPC 全部静默失败。**

现象：前端 `listen('spectrum')` / `listen('state')` 全部收不到，`invoke('orb_click')` 也没有反应，
但 WebView 正常渲染、没有任何报错。加缺省 capabilities 后立刻收到 `spec=605 state=6`。

修法：`app/src-tauri/capabilities/default.json`
```json
{
  "identifier": "default",
  "windows": ["orb"],
  "permissions": ["core:default", "core:event:default",
                  "core:window:allow-start-dragging", "core:window:allow-close",
                  "core:window:allow-set-always-on-top"]
}
```
**只授这些**——前端拿不到文件/Shell 权限（铁律：前端不碰文件、不碰麦克风）。

另外：CSP 必须放行 IPC，否则即使有 capabilities 也不通：
`connect-src 'self' ipc: http://ipc.localhost`

第三个坑：**改前端后必须 `touch build.rs` 再 `cargo build`**，否则 Tauri 不会重新嵌入前端资源
（`frontendDist` 的内容在构建时被内联进二进制，光改 html/js 不触发重编译）。
