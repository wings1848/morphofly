**日期**：2026-10-24 03:28 (+08:00)
**背景**：2026-10-24 独立审计指出原证据只有 4 态（缺 S1、S5），且 S5 从未真正到达过。
本文件是修复后的重测。

## 修复的两个问题

### 1. S5 状态机缺口（真 bug）
`set_connected(false)` 原来只在 `is_active_call()`（S1–S4）时跳 S5，
从 S0 调不会跳 → **待机时连不上云端完全没提示，用户以为软件坏了**。

修法：加 `ever_connected` 标记。连过再断 → 一律进 S5；从未连过 → 保持 S0（这是有意的，
避免启动瞬间闪一下异常态）。单测 `disconnect_while_idle_also_goes_s5_after_first_connect` 锁死。

### 2. 巡检器自己到不了 S5
`spawn_state_walker` 里直接调 `set_connected(false)`，但因为从没 `set_connected(true)` 过，
`ever_connected` 一直是 false → 保持 S0。修法：先 `set_connected(true)` 再 `set_connected(false)`。

## 视觉演进过程（诚实记录）

1. 第一版：粒子 alpha 算错（多除了一次 255）→ 几乎看不见
2. 第二版：改成画线连线 → 变成一团乱麻
3. 第三版：改成按景深着色的点，六态开始有差异但不明显
4. 第四版：加 `spread`（粒子分布形态）、`ringGain`、`pulse` 三个维度 → 六态可辨
5. 第五版：球占窗口从 30% 收到 17%，光晕每层压暗 → 达到「深海一点光」而不是整屏发青

**教训**：只靠亮度区分状态不行，必须有形态维度（粒子收/放）+ 时间维度（脉冲）。
