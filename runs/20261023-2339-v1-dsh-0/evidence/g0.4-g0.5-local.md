# 阶段 0 · 接缝 0.4 / 0.5 证据（本机可跑部分）

## 0.5 频谱 → 前端（可脱机验证）

命令：`cargo run -q -p diemeng-core --example spectrum_json -- --seconds 1`
- 输出 30 行 JSON（30fps × 1s），每行 `{bins:[64 float], rms, rms_raw, t_ms}`
- 单测覆盖：静音全 0、440Hz 有能量、响度单调、高频落高频 bin、bin 值域 0..1、短输入不 panic
- `cargo test -p diemeng-core --lib spectrum` → 9 passed

前端侧（原生 ES module，无打包器）：
`node --test app/frontend/test/` → 7 passed
覆盖：六态视觉参数两两不同、StateSmoother 渐进收敛、粒子半径随能量/频谱变化、无 NaN

