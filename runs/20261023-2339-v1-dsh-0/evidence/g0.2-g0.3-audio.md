机器：wings-pc（CachyOS / PipeWire / 真实麦克风 + 扬声器）
命令：`tools/pcrun.sh 'cargo run -q -p diemeng-core --example mic_level -- --seconds 3'`

## 0.2 cpal 原生采集 —— ✅ 通过

```
[mic_level] 打开默认输入设备（16kHz/mono/i16/20ms）…
[mic_level] frame= 148 len=320 rms=0.0145 #
[mic_level] frame= 150 len=320 rms=0.0084
[mic_level] 完成：150 帧 / 48000 采样，平均 RMS=0.0062，峰值 RMS=0.0145
[mic_level] ✅ 原生采集链路正常
```

- 3 秒 → **150 帧**，每帧 320 采样：恰好 20ms/帧 = 50fps，格式正确
- RMS > 0：设备真的在收音（不是空流）
- **完全不经过 WebView**（铁律：WebView 永不碰麦克风）

## 0.3 rodio 播放 + I4 即时打断 —— ✅ 通过

由 T1 交付时的临时探针实测（探针已删，未入库）：

```
[probe] 设备: OutputFormat { device_sample_rate: 48000, channels: 2, nominal_rate: 24000 }
[probe] 抗抖动容量: 500ms
[probe] append_pcm16 写入 12000 采样（24k，期望≈12000）
[probe] stop_now 耗时 773ns，打断后 queued_frames=0
[probe] 16k 320 采样 → 写入 479（期望≈480 @24k）
[probe] 300ms 内音频线程取走 9728 采样，剩余队列 2272
```

**不变量 I4 实测：`stop_now()` 773 纳秒，队列立即归零。**
实现方式：常驻 RingSource + generation 原子计数（不走 rodio 的 `clear()`/`stop()`，那两个会等队尾）。

## 环境陷阱（备忘）

- KWin/Wayland 下 Tauri 窗口需要 `GDK_BACKEND=x11` + `WEBKIT_DISABLE_DMABUF_RENDERER=1` + `LIBGL_ALWAYS_SOFTWARE=1`，否则报 `Failed to create GBM buffer`
- `grim` 截不了图（KWin 不支持 screencapture 协议），用 `spectacle -b -n -f -o`；单窗口用 ImageMagick `import -window <id>`
