## 一个重要的坑（浪费了 1 小时）

**`import -window <id>` 在 KWin/XWayland 下截到的是过期的合成图层。**

现象：Rust 侧日志明确显示状态已到 S2、频谱推了 700+ 帧，
但 `import -window` 截出来的图永远是启动那一帧（画面停在「点一下开始说话」）。
一度怀疑是 IPC / CSP / 前端缓存问题，全部排查后都不是。

**正确做法**：用 `spectacle -b -n -f -o` 截**整个屏幕**，再按窗口坐标裁剪。
`spectacle` 走 KWin 原生接口，能拿到实时合成结果。

这条已写进 `tools/pcscreenshot.sh` 的注释，避免后人再踩。

## 架构

```
app/src-tauri/src/
  main.rs       窗口 + IPC 命令 + 频谱推送 + 状态巡检（QA）
  voice.rs      VoiceSession：连云端 / 麦克风推流 / 播放 / 打断 / 静音超时
```

`VoiceSession::run()` 用一个tokio 任务跑采集推流，另一个跑事件处理（播放 + barge-in），
主循环只等「状态离开通话态」就收尾。静音 30 秒自动退出（验收 F9）。
