# spec · 蝶梦语音智能体 V1（本轮：阶段 0 + 阶段 1）

## 背景

现在指挥 AI 干活要开电脑打字看屏幕；手被占着时（做饭/开车/躺着）干不了。
蝶梦把「说人话 → 派活 → 听结果」变成一条不用手的通道。

## 目标（本轮可交付）

启动 App 后，屏幕上只有一个蓝色小球；点一下进通话，对着麦克风说「把 diemeng 的 README 补一段怎么跑」，语音模型听懂并转成任务交给 DSH，DSH 实际执行，执行完 App 用语音说出来。**全程不碰键鼠。**

## 分层（架构已冻结，来自 docs/开发方案.md）

| 层 | 技术 | 职责 |
|---|---|---|
| UI | WebView + Canvas2D | 只画球，只收频谱数字 |
| Core | Rust | 音频采集/播放、VAD、状态机、WS、任务表 |
| 云 | 实时语音模型（StepFun 优先，Qwen 备选） | 听懂、决策、说话 |
| 执行 | DSH（`dsh --profile acp`） | 规划、写码、跑命令 |

## 本轮范围

- 阶段 0：7 个接缝（G0.1–G0.7）全绿
- 阶段 1：双工音频链路 + 小球 + 点击进出 + 字幕 + 延迟数字

## 不做（本轮明确不做）

AEC / 唤醒词常驻 / 任务表持久化 / 主动汇报排队 / 打包分发 / 移动端 / ESP32 / Windows·macOS 构建

## Press Release（假设 V1 已上线）

> **一句话就能派活，不用碰电脑**
> 蝶梦是一个常驻桌面的蓝色小球。点一下（或以后喊「小蝶」），直接说你要什么；它把你的话变成任务交给电脑上的编码 agent，agent 干完活，它自己开口告诉你结果。全程眼睛可以离开屏幕，手可以继续忙别的。

## FAQ（5 条，验收表至少 1 行来自这里）

1. **谁用？** 手被占着但要指挥电脑的人（做饭、修东西、开车前）。
2. **失败会怎样？** 云端断 → 小球转暗提示并保留任务；DSH 卡住 → 语音能问进度、能喊停。
3. **成本多少？** 实时语音约 ¥3.8/小时（连续对话含累积），开发期 200 轮测试 < ¥5。
4. **不做会怎样？** 继续「有想法时手不开」——想法当场流失。
5. **必须联网吗？** 是。语音理解在云上；本地只跑状态机、音频、唤醒词（阶段 4）。
