# V2 目标

按用户 11 条新需求推进，核心是**让蝶梦真正可用**，而不是加功能。

## 范围

### P0 · 不解决就没法用
1. 窗口关不掉/找不回（无托盘、无边框、置顶）
2. 外放自我打断（无 AEC）
3. 回复不够简洁

### P1 · 核心能力缺口
4. 多 agent 管理 + 语音切换工作目录/模型
5. 复杂任务先规划
6. 意图确认

### P0.5 · 验收表里的假通过（本轮发现）
7. cancel_task 不真停 DSH
8. append_requirement 不发给运行中 DSH
9. ACP 事件不按 sessionId 过滤
10. 每任务 spawn 进程（慢 2.8s）
11. 打断不停云端生成

## 不在范围
- ESP32（需重新设计架构）
- 安卓（2-3 周）
- Web 端（待定）
- 内存原生重写（等用户决策）

## 成功标准
用户能在外放环境（不戴耳机）下完成一次完整的
「喊小蝶 → 派活 → 干完主动汇报」流程，不需要 pkill。
