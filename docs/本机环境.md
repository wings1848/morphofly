# 开发环境说明

## 为什么有这台机器和 wings-pc 两台

| 机器 | 角色 | 限制 |
|---|---|---|
| 本机 `wings-tx-us1`（Debian 13 云主机，2C/3.6G） | 写代码、跑纯逻辑测试、跑 ACP 探针、管仓库 | **无音频设备、无桌面**，不能跑 cpal/rodio/GUI |
| `wings-pc`（CachyOS，16C/15G，PipeWire + KWin/Wayland） | 真机音频与 GUI 实测 | 是用户的日常主力机，不要在它上面留常驻进程 |

## 本机的 Rust 编译依赖

本机没有 sudo。cpal 在 Linux 上需要 ALSA 头文件与 `pkg-config`。
解决办法：把 deb 解包到 `~/.local/sysroot`，用 `tools/dev-env.sh` 注入编译环境。

```bash
source tools/dev-env.sh
cargo test
```

## 远程执行

```bash
tools/pcsync.sh                 # 本地 -> wings-pc 同步（不含 target/、.git/、密钥）
tools/pcrun.sh 'cargo test'     # 在 wings-pc 上执行
tools/pcscreenshot.sh /tmp/x.png # 在 wings-pc 上截图（spectacle，已验证可用）
```

wings-pc 上的仓库路径：`/home/wings/Code_Project/diemeng`
（用户名与路径恰好与本机相同，同步脚本因此更简单）

## 密钥

**任何密钥都不进仓库。** 只从环境变量或 `~/.diemeng/credentials`（600）读。
`~/.diemeng/config.toml` 里只写环境变量名（`api_key_env`），不写值。
