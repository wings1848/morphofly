# 音频路由（重要：决定「真正出声」是否成立）

## 问题

2026-10-24 独立审计发现：wings-pc 的 **默认音频输出是虚拟回环设备**，
不是物理扬声器：

```
$ pactl get-default-sink
alsa_output.platform-snd_aloop.0.analog-stereo     ← snd_aloop 虚拟回环
```

`snd_aloop` 是 ALSA loopback 模块，声音进了它等于进了 /dev/null，
**不会从喇叭出来**。

所以此前证据里写的「38400 帧音频真正送进声卡」，准确说法是
**「38400 帧音频送进了 PulseAudio 默认 sink」**——
sink 存在、数据在流动、队列在消费，但**用户听不见**。

## 修法

### 1) 测试前把默认 sink 切到物理设备

```bash
tools/pc_audio_route.sh                 # 列出所有 sink 并标出物理/虚拟
tools/pc_audio_route.sh --physical      # 切到第一个物理 sink
```

### 2) 验证真的出声

```bash
tools/pcrun.sh 'speaker-test -t sine -f 440 -l 1'   # 应听到 beep
tools/pcrun.sh 'cargo run -q -p diemeng-core --example duplex ...'
```

### 3) 用耳机避免回授

没有 AEC 之前，外放会让模型听见自己的声音（自我打断）。
V1 的验收要求是**戴耳机**（docs/开发方案.md 阶段 1）。

## 代码侧的对应

`AudioPlayer` 走 `DeviceSinkBuilder::open_default_sink()`，即系统默认 sink。
所以**默认 sink 是什么，就播到哪里**——这是正确行为，但必须在验证据里
如实记录当时用的是哪个 sink。

证据文件里写「真正出声」之前，必须附 `pactl get-default-sink` 的输出，
且必须是物理设备（不是 `*_aloop_*`，不是 `*_test`）。
