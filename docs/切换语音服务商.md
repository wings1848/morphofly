# 怎么换语音服务商（不改代码）

## 为什么需要这份文档

2026-10-24 实测证明 StepFun 的 VAD 有 1.6 秒硬下限，端到端 2–7 秒，
达不到验收要求（<800ms）。要达标只能换 provider。

架构上一直要求「provider 全配置化，改一行切换，不改代码」（验收 A5）。
这份文档就是操作步骤。

## 切换步骤

### 1. 改 `~/.diemeng/config.toml`

```toml
[realtime]
provider = "qwen"
# ⚠️ 必须带 WorkspaceId，不是通用 dashscope 域名
endpoint = "wss://<你的WorkspaceId>.cn-beijing.maas.aliyuncs.com/api-ws/v1/realtime?model=qwen3.8-omni-flash-realtime"
model = "qwen3.8-omni-flash-realtime"
voice = "Tina"
api_key_env = "DASHSCOPE_API_KEY"
```

### 2. 放密钥（**不要放仓库**）

```bash
# 方式 A：环境变量
export DASHSCOPE_API_KEY=sk-xxxx

# 方式 B：凭据文件（推荐，600 权限）
echo 'DASHSCOPE_API_KEY=sk-xxxx' >> ~/.diemeng/credentials
chmod 600 ~/.diemeng/credentials
```

### 3. 验证

```bash
cargo run -q -p morphofly-core --example ws_roundtrip -- testdata/audio/04_ack_zai.mp3
```

看输出里的 `provider` 和 `model` 是否已经是 Qwen。

## Qwen 与 StepFun 的差异（文档口径，待实测）

| 项 | StepFun | Qwen | 影响 |
|---|---|---|---|
| 端点 | `api.stepfun.com` | `{WorkspaceId}.cn-beijing.maas.aliyuncs.com` | **必须带 WorkspaceId** |
| 首音频 | 实测 2–7s | 官方口径 1.37s | 待测 |
| VAD 参数 | **不生效** | 待测 | 关键 |
| 手动 commit | 支持但慢（5s） | 待测 | 关键 |
| 音频历史 | 未查 | 600 秒截断 | 长对话会「忘事」 |
| 输入格式 | pcm16 | pcm16 16k mono | 同 |
| 输出格式 | pcm16 | WAV 24k | 需确认是否 pcm16 裸流 |
| 上下文累积计费 | 是 | 是（B 类） | 约 ¥3.8/小时 |
| 限流 | 未查 | 60 RPM | 单用户够用 |

## 已知的 Qwen 坑（来自 docs/技术选型.md，未实测）

1. **WS 地址必须带 WorkspaceId**——不是 `dashscope.aliyuncs.com`
2. **输出模态决定事件名**：只开 text 收 `response.text.delta`；带音频收 `response.audio_transcript.delta`
3. **联网搜索与工具调用互斥**：`enable_search` 和 `session.tools` 不能同时开
4. **MCP 工具发现是异步的**：`session.updated` ≠ 工具可用，要等 `mcp_list_tools.completed`
5. **`response.create` 会打断**：有 in-flight 回复时要排队等 `response.done`
6. **3.8 音频+文本双计费**：音频和对应文本分别计费

## 代码侧要改什么

**什么都不用改。** 只要：
- `Provider::Qwen` 已经存在（`core/src/config.rs`）
- `providers/qwen.rs` 提供了端点和低延迟 session 预设
- 事件解析复用 `stepfun::parse_event`（协议同构）

如果实测发现差异，只需改 `core/src/realtime/providers/qwen.rs`，
`client.rs` 和上层全部不动。

## 切换后必须重测的验收项

1. `evidence/p1-vad-parameter-sweep.md` 那组参数扫描（看 Qwen 的 VAD 参数是否生效）
2. 手动 commit 模式的延迟（`core/examples/manual_vad.rs`）
3. 工具调用格式（StepFun 要嵌套格式，Qwen 待确认）
4. 音频格式（输出是不是裸 pcm16）
5. 端到端延迟 100 次采样
