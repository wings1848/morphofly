
## 怎么用

1. 启动后屏幕中间出现蓝色小球
2. **喊「小蝶」** 或 **点小球** → 进入聆听态（变亮、粒子加速）
3. 说话，比如「帮我看看蝶梦项目现在什么状态」
4. 它回应，或派活给 DSH 后台执行
5. 活儿干完，它**自己开口**汇报
6. 想打断：直接说话，0.3 秒内它闭嘴

## 起不来怎么办

```bash
# 看真实报错
./蝶梦-0.1.0-x86_64.AppImage 2>&1 | tail -20
```

| 现象 | 原因 | 处理 |
|---|---|---|
| `libfuse.so.2` 找不到 | 缺 FUSE | `./蝶梦-0.1.0-x86_64.AppImage --appimage-extract-and-run` |
| 窗口白屏/黑屏 | GPU 驱动 | 前面加 `WEBKIT_DISABLE_COMPOSITING_MODE=1 WEBKIT_DISABLE_DMABUF_RENDERER=1` |
| 提示「唤醒词没启用」 | 模型没找到 | 把完整日志发我 |
| 连不上语音服务 | key 不对/网络 | 检查 `~/.diemeng/credentials` |
| 直接说「不能执行」 | **ARM 机器** | 这个包是 x86_64，需要重新编译 |

## 已知问题（别当成 bug 报）

1. **内存约 500MB** —— WebKitGTK 固有开销，不是泄漏
2. **外放会自我打断** —— 回声消除（AEC）没做，**戴耳机就没事**
3. **英文项目名识别不准** —— 说「diemeng」可能听成 daimian/diamond，说「蝶梦」才对
4. **刚启动喊「小蝶」可能没反应** —— 模型加载要 1 秒，稍等再喊
5. **黑框不显示内容时** —— 可能是渲染问题，加环境变量试试

## 测试重点（麻烦重点看这五条）

1. **喊「小蝶」能不能唤醒** —— 多试几次，包括小声、远一点
2. **说完话到听见回答，体感多久** —— 我这边实测 0.8 秒
3. **它说话时你插嘴，它停不停** —— 应该 0.3 秒内闭嘴
4. **派个活试试** —— 比如「帮我看看 /home 下有什么」，看它会不会主动回来汇报
5. **有没有误触发** —— 没喊小蝶它自己蹦起来

## 这次修的两个 bug（说明为什么重新打包了）

### 1. 唤醒词启动时序错

原来 `spawn_wake_listener` 在环境变量设好**之前**就调用了，
导致 AppImage 场景下去 `~/.diemeng` 找模型，找不到就静默降级 ——
**等于你装了个不能唤醒的版本**。

现在挪到 `.setup()` 里、设完 `MORPHOFLY_BUNDLE_DIR` 之后再启动。

### 2. 一次发言触发多次 commit

原逻辑「只要音量超过阈值就重置已发送标志」，被风扇/键盘底噪反复重置，
一次发言触发了 4 次 commit。

改成三态状态机（Idle / Speaking / Cooldown），要求**连续 3 帧有声**才算真开口。
现在一次发言只 commit 一次。
