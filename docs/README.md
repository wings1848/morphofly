## 一句话说清

现在指挥 AI 干活要开电脑、打字、看屏幕。
**手被占着的时候（做饭、开车、躺着、修东西）就干不了。**

蝶梦把手解放出来：
- 不用看屏幕
- 不用按键
- 喊一声就行

**只解决一件事**：说人话 → 派活 → 听结果。

## 三条设计铁律

### ① 语音前台只负责嘴和耳朵

**做**：听懂、澄清、整理任务、转交、汇报
**不做**：规划、拆解、写代码、读文件、跑命令

靠**物理隔离**保证——云端语音模型手上只有 4 个函数，根本没有那些工具。

### ② 语音与任务互不阻塞

后台跑 3 个任务，照样能说话、随时插话。
语音断了任务继续；任务卡住语音能问。

### ③ 不需要说明书

打开就能用。没有登录页、没有配置向导、没有「点击开始」。

## 技术选型（已按调研修正）

| 层 | 选择 | 一句话理由 |
|---|---|---|
| 实时语音 | 阿里云百炼 `qwen3.8-omni-flash-realtime` | 首音频 1.37s、打断 71ms、**≈¥3.8/小时**（含累积） |
| 桌面壳 | **Tauri 2.x（Rust）** | 体积最小、移动端官方支持 |
| **音频** | **cpal + rodio + webrtc-audio-processing（全原生）** | **WebView 采音会断掉 AEC 参考信号** |
| UI | WebView Canvas/WebGL | 只收频谱数字，**永不碰麦克风** |
| 唤醒词 | sherpa-onnx KWS（桌面/移动）+ esp-sr（ESP32） | **双引擎**：sherpa 在 ESP32 上跑不了 |
| ESP32 | C/C++（ESP-IDF + esp-sr + LVGL） | Go/Rust 内存与闭源库都不允许 |

> ⚠️ **最重要的一条**：别在 WebView 里碰麦克风。
> 原因：AEC 拿不到参考信号、Linux 上不可用、iOS 可视化归零。

### ③ 唤醒词就用「小蝶」吗？

**这个问题已经解决了，不用你纠结了。**

实测发现一个关键参数 **`num_trailing_blanks=4`**：

| 配置 | 召回 | 误唤醒 |
|---|---|---|
| 默认（1） | 8/8 | **1/8**（「小蝶儿」误触发） |
| **改成 4** | **8/8** | **0/8** ✅ |

**延迟零代价，一行代码。**

- **A. 就用「小蝶」**（推荐）—— nb=4 已经够用
- B. 用「小蝶小蝶」—— 更稳，但要说两遍
